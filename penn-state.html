Penn State Soccer Website

Project Overview

A comprehensive soccer analytics platform designed for Penn State soccer, featuring advanced player statistics, comparison tools, and squad building capabilities.

This web application provides an intuitive interface for analyzing player performance, comparing multiple players side-by-side, and creating custom squad formations with detailed player metrics.

Login Page

Secure authentication interface with a clean, modern design that welcomes users to the Penn State soccer analytics platform.

Index Page

The main dashboard providing an overview of the platform's features and quick access to all major sections of the application.

Player Page

Detailed individual player statistics and performance metrics, displaying comprehensive data visualization and analytics for in-depth player analysis.

Player Comparison Page

Side-by-side player comparison tool enabling coaches and analysts to evaluate multiple players simultaneously across various performance metrics.

Squad Builder Page

Interactive squad formation builder allowing users to create and visualize custom team lineups with detailed player information and tactical positioning.
